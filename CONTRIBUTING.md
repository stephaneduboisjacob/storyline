# Contributing

This repository contains a product concept, design specifications, a static-site prototype, and a small helper service. Read the README and consent/security documents before suggesting changes to recording or synthetic-voice behavior.

Do not add real recordings, voice samples, family records, credentials, or identifying customer information. Keep concept examples fictional and clearly labeled.

The static site can be previewed with `python3 -m http.server 8000 --directory site`. The geo-language helper has separate configuration and is not required for that preview.

No license has been selected yet; public visibility does not grant permission to reuse the code.
