# Security Policy

StoryLine is a concept involving potentially sensitive voice recordings, family stories, and identity data. Do not add real personal data, voice samples, call recordings, credentials, or private deployment details to issues or pull requests.

Do not report suspected vulnerabilities in a public issue. Contact the maintainer privately at [jacobstephane@outlook.com](mailto:jacobstephane@outlook.com) with a concise description and safe reproduction steps.

The repository is not a completed or audited recording service. Do not use it to collect real recordings or generate a person's voice.

Contact: Stephane Jacob <jacobstephane@outlook.com>
